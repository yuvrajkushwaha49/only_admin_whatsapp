# Automated Replies and Keyword Triggers

## What are Automated Replies?
Automated replies allow businesses to respond instantaneously to customer inquiries 24/7 without manual agent intervention.

## Trigger Types
1. **Welcome Message:** Automatically sent when a new contact messages your WhatsApp number for the first time.
2. **Out of Office / Away Message:** Triggered when customers message outside defined business operational hours.
3. **Keyword Triggers:** Exact match or contains triggers (e.g., customer texts "CATALOG" -> bot instantly replies with product brochure PDF).
4. **Interactive Button Responses:** Triggers specific responses when a user taps a quick reply button (e.g., "TALK_TO_AGENT").

## Configuring Rules
- Set matching conditions (Exact Match, Starts With, Contains, Regex).
- Define reply action: Plain text message, media template, or tag assignment.
- Enable Cooldown: Prevent spamming by throttling automated replies to the same contact within a 15-minute window.

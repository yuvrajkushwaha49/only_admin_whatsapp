# Chatbot Builder & Interactive Flows

## Chatbot Builder Overview
The Chatbot Builder enables creating guided decision trees and conversational flows on WhatsApp using interactive buttons, menus, and conditional branches.

## Core Capabilities
- **Quick Reply Menus:** Present users with up to 3 clickable buttons (e.g., "Track Order", "Browse Products", "Customer Support").
- **List Messages:** Present interactive menu lists with up to 10 options categorized by sections.
- **Dynamic Variable Capture:** Store customer responses into custom fields for CRM synchronization.
- **Human Handover:** Escalate conversation from the bot to a live human agent inside the Team Inbox when complex issues arise.

# Workflow Automation and Webhooks

## Event-Driven Automations
Workflow automation connects WhatsApp interactions with external systems via Webhooks and REST APIs.

## Supported Workflow Triggers
- **Contact Created / Opted In:** Trigger welcome drip sequences.
- **Tag Added:** Automatically send specialized follow-up templates when a lead tag is attached.
- **Inbound Message Received:** Forward customer text to your custom webhook URL or CRM.
- **Delivery Status Updates:** Real-time webhooks notify external endpoints when messages transition to `sent`, `delivered`, `read`, or `failed`.

## API Integration
Developers can use our documented REST API to trigger template messages programmatically from external eCommerce or CRM platforms (e.g., Shopify, WooCommerce, Zapier).

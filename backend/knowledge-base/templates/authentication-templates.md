# Authentication Message Templates

## Definition & Purpose
Authentication templates allow businesses to authenticate users with one-time passcodes (OTPs) during login, account verification, or password reset processes.

## Structure & Security Requirements
- **One-Time Password Button:** Meta offers specialized one-tap autofill or copy code buttons.
- **Copy Code Button:** Recipients can copy the verification code to their clipboard with a single tap.
- **Zero Promotional Content:** Absolutely no marketing or general text allowed.
- **Code Expiry Notice:** Can specify expiration duration (e.g. "Expires in 10 minutes").
- **Security Disclaimers:** Meta automatically attaches standard WhatsApp security notices (e.g. "Do not share this code with anyone").

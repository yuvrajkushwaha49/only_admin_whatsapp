# Media Message Templates (Images, PDFs, Videos)

## Media Header Types
Templates can incorporate rich multimedia headers to enhance customer engagement:
1. **IMAGE:** Formats: JPG, PNG. Recommended resolution: 1200x628 pixels. Max size: 5MB.
2. **DOCUMENT (PDF):** Format: PDF. Ideal for brochures, price lists, event itineraries, and invoices. Max size: 100MB.
3. **VIDEO:** Format: MP4 (H.264 video codec, AAC audio). Max size: 16MB.

## Media Handling in Broadcast Campaigns
- When sending a media template in a campaign, users upload or provide a public URL to the media asset.
- The platform can host assets or fetch them directly from your secure AWS S3 bucket.
- Meta caches media assets for optimal delivery speeds across global recipients.
